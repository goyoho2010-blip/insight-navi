# 인사이트 나비(NAVI) 통합 컨설팅 솔루션 — 통합 대문

천명의선택 입시전문연구소(김태영 원장)의 5단계 입시 컨설팅 흐름을 **로그인 없이** 한 화면에서
보여 주는 통합 대문(허브) 앱입니다. 실전 앱 4종은 암호를 그대로 둔 채, 대문 안에서 **체험판**으로
같은 화면 감각을 눌러 볼 수 있게 만들었습니다.

## 화면 구성 (6개)

| 화면 | 내용 | 상태 |
|---|---|---|
| 🏠 통합 대문 | 5단계 로드맵(① 진로탐색 → ② 학습관리 → ③ 수시진단 → ④ 면접훈련 → ⑤ 정시 내 위치), 앱 카드 5장, 상담·도입 문의, 원장님 실전용(암호) 바로가기 4종 | 오픈(로그인 없음) |
| 🧭 진로NAVI 체험 | 샘플 학생 선택 → 계열 적합도 → 추천 학과 3개 → 추천 도서 3권(저자·키워드·세특 연계 질문) → 권장 선택과목 | 체험판 |
| 📚 학습NAVI 체험 | 주간 KPI(평균 완료율·D-7 위험교재·전주 대비·점검일 임박), 교재별 진도·회독 표, 과목별 이번 주/전주 막대 차트, 컨설턴트 코멘트 | 체험판 |
| 📋 수시NAVI 체험 | 학업·진로·공동체 역량 점수 카드(항목별 배점 합계 = 점수), 역량 차트, 세특 강점 3 / 보완 코칭 3, 지원 가능 전형 요약 | 체험판 |
| 🎤 면접NAVI PRO 체험 | 세특 근거 문장 3개 → 1단계 기본 / 2단계 심화 / 3단계 진실성 검증 질문, 토글형 답변 체크포인트 | 체험판 |
| 📊 내 위치 NAVI | 2027 가채점 등급컷(7과목×1~3등급), 4,165개 모집단위 반영비율 예시, 판정 구간(안정·적정·소신·도전), 실사용 앱 바로 열기 | 실사용 링크 |

## 체험판 원칙

- **API 비용 0원**: OpenAI 호출 없음. 모든 문장·점수는 `demo_data.py`에 내장.
- **개인정보 0건**: 등장 학생 2명(김서연 고2 자연계열, 이준호 고1 인문·상경)은 **가명(창작)**.
  실존 학생 이름·학교·생활기록부 문장 없음.
- **DB 미연결**: Supabase·DB·외부 API 연결 없음. 입력값 저장 기능 자체가 없음.
- **실전 앱 불변**: `insight-navi2`, `choice1000navi`, `learning-navi`, `choice1000-career-navi`는
  건드리지 않았고 암호 잠금도 그대로입니다.

## 구조

```
app.py                  화면(Streamlit) — 대문 + 체험판 4종 + 내 위치 안내
demo_data.py            100% 내장 샘플 데이터(가명 학생 2명 · 2027 등급컷 · 모집단위 예시)
requirements.txt        streamlit / pandas / altair
.streamlit/config.toml  라이트 테마(네이비+틸)
tests/test_demo_data.py 데이터 무결성 · 가명/PII 없음 · 외부 의존 없음
tests/test_app.py       6개 화면 렌더링 스모크 테스트(AppTest)
```

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 검증

```bash
python -m pytest tests -q     # 25 passed
```

- `demo_data` 무결성: 학생 2명 고정, 도서·학과·질문 필드 완비
- 수치 정합성: 학습 KPI 평균·전주 대비·D-7 위험교재 판정, 수시 역량 점수 = 항목별 배점 합계
- 가명/PII: 전화번호·주민번호·이메일·학교명 패턴 0건
- 외부 의존: `openai`·`supabase`·`requests` 등 import 0건, API 키 흔적 0건
- 화면: 6개 페이지 예외 0건, `st.error` 0건, 헤드리스 브라우저 콘솔 오류 0건(6개 화면 모두)
